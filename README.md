A site to study English

写给apple用户的话：
1. 用 HTTPS 打开（GitHub Pages ）(https://wanuo54.github.io/studyen/ )
2. Safari 打开后，直接“添加到主屏幕”。
3. 以后只从主屏图标进，别和 Safari 来回切  因为两边数据不互通。
4. 在主屏图标里配 AI Key、导入文章。
5. 长按句子看译文，单击单词查词。
6. 数据存在手机本地，Safari 可能自动清理。定期“我的文章 → 导出备份”，存 iCloud。
7. 换手机：旧机导出备份，新机导入。
8. 主屏打开是空白？在图标里重新配一次就行。

一句话：加主屏、只用主屏、常备份。


苹果用户暂不支持
写给Android用户的话：
网站地址： https://wanuo54.github.io/studyen/ 
本项目提供APK安装包、网页版两种使用方案。
 
📦方案一：APK安装包（安卓推荐）
 
1. 下载APK文件到手机，完成安装即可直接使用。
​
2. ✨优点
 
- 独立App，不需要浏览器，桌面直接点开；
​
- 内置网页内核，IndexedDB本地存储功能完整可用；
​
- 不受GitHub Pages网络限制，安装后可离线打开。
 
⚠️重要注意
 
1. 安卓系统会拦截未知来源安装包，需要在系统设置开启允许安装未知应用权限。
​
2. 所有数据仅保存在手机本地，不会上传云端。卸载App、清除App数据，保存的全部内容会丢失，无法跨设备同步。
​
3. 项目更新后，需要重新下载新版APK覆盖安装，没有内置自动更新。
​
4. 本APK为网页打包产物，不会收集你的隐私数据。
 
🌐方案二：网页版（无需下载）
 
访问地址： https://wanuo54.github.io/studyen/ 
 
1. 国内直连github.io经常打不开，需要合适网络环境访问。
​
2. 不要在微信、QQ内置浏览器打开，会出现功能异常。
​
3. 推荐使用Chrome/Edge浏览器，右上角菜单选择添加到主屏幕生成桌面快捷方式。
​
4. 网页数据存于浏览器，清理浏览器缓存会丢失本地存储数据。
 
📌通用提醒
 
1. 重要数据建议手动备份，没有云端同步。
​
2. 不要使用无痕隐私模式，会导致本地存储失效。
​
3. 网页版更新：代码推送GitHub后等待1‑3分钟自动部署生效；APK需要重新打包下载。
 
❗常见故障
 
- APK安装被拦截：选择继续安装，开启未知来源安装权限。
​
- 打开空白：检查打包资源路径，可切换网页版测试。
​
- 数据消失：卸载、清除应用缓存会清空本地数据库。
